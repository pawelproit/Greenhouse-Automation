# 🌱 Arduino Greenhouse Automation

Automated greenhouse monitoring and control system based on an Arduino microcontroller.

## Features

* Temperature monitoring
* Air humidity monitoring
* Soil moisture monitoring
* Sunlight intensity measurement
* Automatic relay control
* Environmental threshold management
* Real-time sensor data collection

## Technologies

* C
* Arduino
* Embedded Systems
* Linux

## System Components

* Temperature sensor
* Humidity sensor
* Soil moisture sensor
* Light sensor
* Relay modules
* Water pump and ventilation control

## How It Works

The system continuously monitors environmental conditions inside the greenhouse. When predefined thresholds are exceeded, appropriate relays are activated automatically to maintain optimal growing conditions.

Examples:

* Low soil moisture → water pump activation
* High temperature → ventilation activation
* Low light intensity → lighting activation

## Project Goals

The project was designed to explore embedded systems programming, sensor integration, and automation using Arduino.
